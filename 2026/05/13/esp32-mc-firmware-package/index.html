在单片机上运行 Minecraft 服务端，实现单片机开服

发表于2026-05-13|更新于2026-11-13|技术
|浏览量:

32mc 项目开发完成后，为了让非开发者也能体验在 ESP32 上跑 Minecraft，我打包了这份「ESP32-MC 资料包」。不用装 PlatformIO，不用配编译环境，只要一块 ESP32-S3 开发板和一根 USB 数据线，四步就能刷写完成。

资料包内容

文件 大小 说明
esp32mc-full.bin 837 KB 预编译完整固件，包含 bootloader、分区表和应用程序
CH340驱动.EXE 825 KB CH340 USB 转串口驱动（Windows 安装包）
flash_download_tool/ - 乐鑫官方烧录工具，图形化界面，无需命令行

为什么需要这个资料包

开源项目最大的痛点往往不是代码质量，而是「普通人跑不起来」。32mc 的源码需要安装 PlatformIO、配置 Arduino 框架、下载依赖库、修改 WiFi 配置、选择正确的编译目标……每一步都可能劝退一个想尝鲜的人。

资料包把这些门槛压到最低：装驱动、开工具、选固件、点烧录，全程不超过 5 分钟。对于想在自己的 ESP32-S3 上体验 Minecraft 的用户，这就是最简单的方式。

使用方法

第一步：安装驱动。 运行 CH340驱动.EXE，按提示完成安装。插上 ESP32-S3，设备管理器里应该出现 COM 端口。

第二步：打开烧录工具。 进入 flash_download_tool 目录，运行可执行文件，芯片类型选 ESP32-S3，下载模式选 UART。

第三步：加载固件。 添加 esp32mc-full.bin，起始地址设为 0x0，勾选 DoNotChgBin。选对 COM 端口，波特率 1152000，点击 START。

第四步：配置 WiFi。 刷写完成后复位开发板，通过串口（115200 bps）发送 WiFi 配置命令，或访问 Web 控制面板 http://<esp_ip>/ 完成后续配置。

适用硬件

  • ESP32-S3 开发板（esp32-s3-devkitc-1 或兼容型号）
  • ST7735 / ST7735S SPI 屏幕（160×128）
  • CH340 / CP2102 USB 转串口芯片（市面上大多数 ESP32 开发板自带）

对应的服务端

固件面向 bareiron 服务端 1.21.8 / 协议 772 适配，默认连接 192.168.3.144:25565，刷写后可通过 Web 面板修改。推荐在同一局域网内部署 bareiron，体验最好。

好软件不仅要写出来，还要让别人跑起来。从源码到资料包，是开发者到用户的最后一步。
