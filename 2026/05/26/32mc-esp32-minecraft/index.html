在 ESP32S3N16R8 上运行 Minecraft 客户端

发表于2026-05-26|更新于2026-11-13|技术
|浏览量:

32mc 是一个跑在 ESP32-S3 上的轻量 Minecraft 在线客户端。它连接 Minecraft Java 协议服务端（目前主要面向 bareiron），把服务端下发的区块解码成本地体素窗口，再实时渲染到 ST7735 屏幕上。目标不是完整复刻 Java 客户端，而是在极低资源的设备上做出可玩的 Minecraft。

功能特性

  • 基于 ESP32-S3 + ST7735 的 3D 体素渲染
  • 支持 Minecraft 完整登录流程（Handshake / Login / Configuration / Play）
  • 解析并应用服务端的 Chunk Data and Update Light 数据包
  • 支持移动同步、切换手持物品、破坏方块、放置方块
  • 支持远程玩家可视化，附近玩家实时显示
  • 内置 Web 控制面板，浏览器即可操控游戏

目录结构

文件 职责
src/main.cpp 程序入口与主循环
src/mc_client.cpp 网络协议收发与状态机
src/render.cpp 体素渲染与 HUD
src/controls.cpp 输入处理、相机与交互逻辑
src/world.cpp 本地体素世界与碰撞/射线检测
src/web_control.cpp WiFi 管理 + Web API/UI
include/game_shared.h 全局配置常量

硬件要求

  • ESP32-S3 开发板（esp32-s3-devkitc-1）
  • ST7735 / ST7735S SPI 屏幕（160×128，可替换其他屏幕）
  • 两个物理按钮（GPIO39 / GPIO40）用于操作

如果接线不同，请修改 include/game_shared.h。

软件环境

  • PlatformIO 构建系统 + Arduino 框架
  • 依赖：Adafruit GFX Library、Adafruit ST7735 and ST7789 Library

快速开始

1. 配置 WiFi 与默认服务器

填好自己 WiFi 的 SSID 和密码再编译烧录。

2. 检查串口配置 — 修改 platformio.ini 中的 upload_port 和 monitor_port。

3. 编译与烧录

4. 打开串口日志

5. 打开 Web 控制面板 — 浏览器访问 http://<esp_ip>/，即可通过网页控制游戏。

默认按键映射

操作 按键
视角 ArrowUp / Down / Left / Right
移动 W / A / S / D
跳跃 Space
破坏 Q
放置 R
物品栏切换 Z / X 或 1~5

Web 控制 API

接口 说明
GET /api/state 获取当前状态
GET /api/mc_cfg 设置联机参数
GET /api/mc_reconnect 强制重连 MC 服务器
GET /api/map 修改按键映射
GET /api/key 按键按下/释放事件
GET /api/release_all 释放全部按键

技术挑战与限制

在 ESP32-S3 上跑 Minecraft 客户端，挑战是全方位的：可用内存只有几百 KB，没有 GPU，SPI 屏幕带宽也有限。为此做了不少针对性优化——本地世界窗口压缩到 16×14×16，靠服务端中心区块流式更新；渲染、碰撞和方块映射全部简化，但不牺牲核心可玩性。

协议层面，当前实现面向 bareiron 服务端（1.21.8 / 协议 772），并针对 ESP32 做了窗口化和低带宽适配。它不是完整的 Java 客户端，只实现了可玩的子集，但足够在 ST7735 小屏幕上体验联机的乐趣。本地离线世界编辑默认关闭；Web 控制面板默认没有鉴权，请只在可信局域网里使用。
